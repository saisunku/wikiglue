# Task: weekly digest

1. Read the entries in `wiki/log.md` from the last 7 days.
2. Read the `wiki/sources/` pages added this week.
3. Write `wiki/digests/<ISO year>-W<week>.md` (front matter `type: digest`):
   - **New this week**: each new source, one line: its kind, title linked, and its main point.
   - **Themes**: if several sources this week touch the same topics, a few lines on what they add
     together, linking the topic pages.
   - **Wiki changes**: topic and tool pages created or notably updated, a few words each.
   - **Cleanup**: a one-line summary of what lint fixed.
   - **Suggested reading**: unchecked items in `_review/research-requests.md`.
   - **Gaps in sources**: lines from the last 7 days in `_review/missing-from-sources.md`, if any.
4. Give the digest a one-line `summary:` in its front matter (the week and its highlights).

Reply with the digest text (under 250 words), nothing else.
